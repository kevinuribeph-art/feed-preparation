# feed-preparation

La Mesa de trabajo de Uribe Visuals: una app web estática (HTML y JavaScript, sin dependencias) para preparar el feed mensual de
Instagram de cada cliente, y el portal donde cada cliente ve su calendario.

- La Mesa: https://mesa.uribevisuals.studio (Cloudflare Pages, con `tools/publicar-mesa.sh`) y, hasta la mudanza,
  https://kevinuribeph-art.github.io/feed-preparation/ (GitHub Pages).
- El portal de clientes: https://clientes.uribevisuals.studio (Cloudflare Pages, carpeta `portal/`).
- El servidor (Supabase): `servidor/`. Las decisiones, en `DECISIONES.md`.
